# ik-site-security

Sist oppdatert: 26.10.2026

WordPress-plugin for sikkerhet på egne og kunders nettsider: innloggingsbeskyttelse, brute-force-sperre, logging, omdirigeringer, HTTPS-tvang, security.txt, REST-feillogg og statusendepunkt. Alt virker likt på alle sider uten innstillinger per side.

- `CHANGELOG.md` - versjonslogg for pluginet
- `ik-site-security.php` - hovedfila som laster pluginet
- `login/` - stil for admin-siden (`admin.css`)
- `modules/` - funksjonsmodulene pluginet består av
- `uninstall.php` - rydder opp når pluginet avinstalleres
